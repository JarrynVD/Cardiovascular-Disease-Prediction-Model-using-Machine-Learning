# Cardiovascular-Disease-Prediction-Model-using-Machine-Learning
The project includes:

Data preprocessing and cleaning
Exploratory data analysis and visualization
Correlation matrix analysis
Feature engineering (BMI calculation)
Outlier removal
Machine learning model training and evaluation

The following machine learning models were implemented and compared:

Support Vector Machine (SVM)
Logistic Regression
K-Nearest Neighbours (KNN)
Decision Tree
Random Forest

Among all tested models, the Support Vector Machine (SVM) achieved the highest prediction accuracy of approximately 73%.

Technologies used:

Python
Pandas
NumPy
Matplotlib
Scikit-learn

This project demonstrates the application of machine learning techniques for medical data analysis and cardiovascular disease risk prediction.
